# Visual Design Guidance

## Requirements

### Discoverable guidance

The Visual Design module has indexed rules, guidelines, and task skills. Metadata references every guidance entry. The coverage map links basic, intermediate, and advanced guidance for general design, color, typography, and layout, and maps applicable supporting design and platform areas.

### Responsive validation

The responsive validation skill defines browser viewport dimensions in CSS pixels and distinguishes them from device-pixel ratio and physical display resolution. Its runner plans portrait and landscape cases with long edges from 256 through 7680 pixels, aspect ratios, 4K and 8K cases, and exact and adjacent-pixel checks for actual width and height breakpoints.

### Evidence boundaries

Automated viewport metrics identify measurable failures and review candidates. Keyboard, visual, localization, zoom, reduced-motion, touch, assistive-technology, native, and physical-device behavior must be reported according to the evidence available. A plan or synthetic metric test is not application-level verification.

### Compatibility

The module preserves existing vendor selection, TypeScript interfaces, and domain style references. Existing breakpoints and target sizes in legacy style data are examples and are not universal standards or conformance evidence.
